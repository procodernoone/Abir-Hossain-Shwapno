# Abir Hossain Shwapno | Portfolio

Personal portfolio of **Abir Hossain Shwapno**, a maker and developer from Bangladesh building robotics, AI, and web projects with ESP32, Flutter, and Python.

**Live site:** [abir-hossain-shwapno.onrender.com](https://abir-hossain-shwapno.onrender.com)

## Featured projects

| Project | What it is |
|---|---|
| **G.A.M.S.** | Gesture Assisted Mobility System: an assistive rover driven by hand gestures from a Flutter app, with an ESP32 dashboard and ESP32-CAM live stream |
| **PINCHSERVO** | Browser hand-pinch controller (MediaPipe) for an ESP32 and SG90 servo |
| **ASTRO ROVER** | Rover robotics project |
| **Lily AI** | Friendly AI assistant with a web interface |
| **Medicare+** | Hospital management system |
| **Patholab** | Offline pathology management built with Flask and SQLite |
| **Neon Dash** | Neon-themed mobile platformer built in Godot for Android |

## About this site

A fast, minimal, single-page portfolio with a notebook-style design.

- Sections: home, about, skills, projects, certificates, contact
- Filterable project grid and certificate gallery with lightbox
- Contact form powered by Formspree
- Animated particle background and scroll reveals
- SEO ready: JSON-LD structured data, Open Graph tags, sitemap, robots.txt, and WebP images

## Tech stack

HTML, CSS, and vanilla JavaScript. No frameworks and no build step. Hosted on Render as a static site.

## Run locally

```bash
git clone https://github.com/procodernoone/Abir-Hossain-Shwapno.git
cd Abir-Hossain-Shwapno/Portfolio
python -m http.server 8000
```

Then open `http://localhost:8000`.
